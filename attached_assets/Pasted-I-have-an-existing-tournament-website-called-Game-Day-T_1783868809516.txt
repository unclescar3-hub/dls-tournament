→ Referrer earns a CASH REWARD
→ The cash reward is tiered based on how many paying referrals they 
  bring in, starting from 10 paid referrals and above
→ Admin sets each tier and its payout value inside the admin panel

- A field to set "points earned per free referral registration"
- A tiered cash reward table (e.g. 10 referrals = ₦500, 
  20 referrals = ₦1200, etc.) that admin can add/edit/delete rows
- An AUTO-CALCULATOR that shows projected referral payouts based 
  on number of referrals — admin inputs a number and it shows 
  total payout at each tier automatically
- A dashboard showing each player's referral count, points earned, 
  and cash earned from referrals

Each player's profile/dashboard should show:

- How many people they've referred
